# Transphere

Односторінковий сайт-візитка маркетологині-консультантки **Анни Мироненко** у стилі
кінематографічної зйомки: закріплений герой із покроковою появою блоків під час скролу,
інтерактивна 3D-сфера, що трансформується (звідси й назва — Trans**form** + S**phere**),
дві теми (темна / світла), світлові смуги на фоні.

**Демо:** відкрийте `index.html` у браузері (або увімкніть GitHub Pages — див. нижче).

---

## Що всередині

Один самодостатній файл `index.html`. Без збірки, без `npm install`.
Усі бібліотеки підключені з CDN:

| Бібліотека | Для чого |
|---|---|
| React 18 (UMD) + [htm](https://github.com/developit/htm) | розмітка та стан |
| [three.js](https://threejs.org/) r128 | 3D-сфера на кастомних шейдерах |

### Секції

- **Інтро** — тільки анімована сфера + підказка «прокрутіть». Меню, ім'я, текст приховані.
- **Скрол-хореографія** — під час прокрутки закріпленого героя блоки з'являються покроково:
  ім'я → «Маркетологиня» зі стрілкою → опис → кнопки → блоки статистики → нижнє меню.
- **Про мене / Послуги / Відгуки / Контакти** — стандартні секції з появою при скролі.

### Взаємодія зі сферою

- обертається сама;
- **наведення курсором** → сфера рожевіє, поверхня трохи прогинається під вказівником;
- прибрав курсор → повертається у фіолетовий;
- під час скролу змінює форму, зменшується та повільно опускається слідом за прокруткою
  до блоку контактів, де плавно зникає;
- кнопка «↑» повертає на початок — сфера анімовано їде назад.

### Інше

- перемикач теми ☀ / ☾ у нижньому меню (також підхоплює системну тему);
- HUD із REC, живим таймкодом і `4K · 24 FPS`;
- дрібні різнокольорові фрагменти коду та поодинокі світлові смуги («комети») на фоні;
- повага до `prefers-reduced-motion`.

## Замінити перед реальним використанням

Контент — плейсхолдерний:

- **ім'я** — `Анна Мироненко` (у `<title>`, шапці, HUD, футері);
- **відгуки** — вигадані (масив `REVIEWS` у `<script>`);
- **контакти** — `@anna_myronenko`, `hello@annamyronenko.com`, `/in/annamyronenko`
  (пошук по файлу);
- форма зв'язку відкриває `mailto:` — для реальної відправки потрібен бекенд або сервіс
  (Formspree тощо).
